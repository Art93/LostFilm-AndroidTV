# LostFilmATV — Releases

Здесь публикуются APK-релизы приложения **LostFilmATV** — неофициального клиента [lostfilm.tv](https://www.lostfilm.tv) для Android TV.

## Что это такое

LostFilmATV — приложение для Android TV, которое позволяет удобно просматривать сериалы с lostfilm.tv прямо на телевизоре с пульта. Написано на Kotlin с использованием Leanback (UI-фреймворк для Android TV).

## Требования

- Android TV / Android 9 (Pie) и выше
- Аккаунт на lostfilm (lostfilm.tv, lostfilm.download и другие зеркала — аккаунт единый)
- Установленный **TorrServe** на том же устройстве или в локальной сети

## Что такое TorrServe

TorrServe — это локальный торрент-стример. Приложение скачивает `.torrent`-файл с lostfilm.tv, передаёт его в TorrServe, и тот сразу начинает стримить видео без полного скачивания.

Скачать TorrServe: [github.com/YouROK/TorrServe](https://github.com/YouROK/TorrServe)

## Установка

1. Скачать APK из раздела [Releases](../../releases)
2. Установить на Android TV (разрешить установку из неизвестных источников)
3. Запустить TorrServe
4. Открыть LostFilmATV — при первом запуске появится экран входа, войти в аккаунт lostfilm

## Автообновление

Приложение автоматически проверяет наличие новых версий при запуске и предлагает обновиться.
